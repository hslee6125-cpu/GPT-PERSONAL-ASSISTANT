# GPT 개인비서 — 아이콘 실행 + 자동업데이트

이 폴더는 계속 같은 위치에서 사용하는 마스터 프로그램입니다.
평소에는 CMD나 PowerShell을 열 필요 없이 **바탕화면의 `GPT 개인비서` 아이콘만 더블클릭**하면 됩니다.

## 최초 1회 설정

1. Node.js 18 이상을 설치합니다.
2. 이 폴더의 `개인비서_초기설정.cmd`를 더블클릭합니다.
3. 필요한 npm 패키지가 자동 설치됩니다.
4. OpenAI API Key를 한 번 입력합니다. 입력 문자는 화면에 표시되지 않습니다.
5. API Key는 Windows DPAPI로 **현재 Windows 사용자 계정에 묶어 암호화**되어 `.private/api-key.dat`에 저장됩니다.
6. 바탕화면에 `GPT 개인비서` 바로가기 아이콘이 자동 생성됩니다.

초기설정을 다시 실행하면 API Key나 모델을 변경하고 바탕화면 아이콘을 다시 만들 수 있습니다.

## 평소 실행

바탕화면의 **GPT 개인비서** 아이콘을 더블클릭합니다.

자동으로 다음 작업을 수행합니다.

1. 이미 서버가 실행 중인지 확인
2. 자동업데이트 확인
3. 필요한 경우 업데이트 다운로드 / SHA-256 검증 / 백업 / 적용
4. API Key를 Windows DPAPI에서 복호화하여 현재 실행 프로세스에만 전달
5. Node 서버를 **검은 CMD 창 없이 숨김 실행**
6. 서버가 준비되면 기본 브라우저에서 `http://127.0.0.1:8787` 자동 열기

아이콘을 다시 더블클릭했을 때 서버가 이미 실행 중이면 새 서버를 만들지 않고 브라우저만 다시 엽니다.

## 서버 종료

평소에는 서버를 계속 켜두어도 됩니다. 직접 종료하고 싶다면 프로그램 폴더의 `개인비서_종료.vbs`를 더블클릭합니다.

## 현재 기능

- 개인 비서: 할 일 / 중요 메모 / 장기 프로젝트
- GPT 레시피 자동 구조화
- Word `.docx` 레시피 업로드
- 한 문서의 여러 레시피 자동 분리 / 선택 저장
- 요리 프로젝트 관리
- 프로젝트별 목표 인분
- 프로젝트 전체 재료 자동 합산
- g↔kg, ml↔L 통합
- 자동업데이트
- 업데이트 SHA-256 검증
- 업데이트 전 자동 백업
- 실패 시 기존 버전 복구
- 바탕화면 앱 아이콘 실행
- API Key DPAPI 암호화 저장

## 자동업데이트 연결

업데이트 엔진은 들어 있지만 최신 파일을 받을 HTTPS 저장소가 필요합니다.
기본 `update-config.json`은 안전을 위해 자동업데이트가 꺼져 있습니다.

```json
{
  "enabled": false,
  "manifestUrl": "https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/update-manifest.json",
  "timeoutMs": 15000
}
```

GitHub 등의 마스터 저장소가 준비되면 `자동업데이트_설정.cmd`로 manifest 주소를 연결할 수 있습니다.

업데이트 과정에서 아래 사용자 데이터 경로는 원격 업데이트가 덮어쓸 수 없도록 보호됩니다.

- `.private/` — 암호화된 API Key / 개인 설정
- `.logs/`
- `.update-backup/`
- `update-config.json`

## 데이터 저장

개인비서, 레시피, 요리 프로젝트의 현재 데이터는 브라우저 localStorage에 저장됩니다.
따라서 같은 PC라도 브라우저 데이터를 삭제하면 데이터가 사라질 수 있습니다. 향후 서버 DB/클라우드 동기화 기능을 붙이는 것이 권장됩니다.
